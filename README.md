# technext-site-posts

Design TechNext social media image posts (3:4, 2160x2880 PNG, images only, no video), one per technext.asia service (mega menu - ERP, AI Solution, Marketing, Technology), using the website's page designs only as REFERENCE - each post is an original, dynamic illustrated poster built around its own concept (perspective music staff, bird's-eye relay track, isometric group tower...), in the TechNext brand fonts and colours. Use when the user asks for social posts per website service/category/menu item, "posts based on the website design", site-style posts, or the next category in this series (e.g. "now do AI Solution").
